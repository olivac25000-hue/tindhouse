# TINDHOUSE

Portal inmobiliario digital de España.

## Nuestra misión
Facilitar la compra, venta y alquiler de viviendas, habitaciones y propiedades.

## Funcionalidades
- Búsqueda de inmuebles
- Publicación de anuncios
- Registro de usuarios y agencias
- Chat entre usuarios
- Servicios complementarios para el hogar

## Tecnología
Next.js, Supabase, Vercel y Stripe.
